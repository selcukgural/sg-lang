NAME
     in - stands between the name and the items in a for

SYNOPSIS
     for i in a..b
            the name i, then the numbers it takes

     for x in xs
            the name x, then the collection it goes over

     for x in read xs, for x in ref xs
            the same, with the items lent

DESCRIPTION
     in is written only in the head of a for: the name of each round comes
     before it, and what the loop goes over comes after it. Everything about
     the loop is on the page of for.

     in is not an operator. Whether a list, a map, a set or a text holds
     something is asked with contains. And since in is a word of the language,
     it cannot be the name of a variable.

EXAMPLES
   A range and a list
         void main() {
             var words = List<string> { "red", "green", "blue" }
             for i in 0..words.length() {
                 print($"{i} {words[i]}")
             }
             for word in read words {
                 print(word.length())
             }
         }

         0 red
         1 green
         2 blue
         3
         5
         4

     After in comes a range, 0..words.length(), or a collection, here lent
     with read.

   Whether something is there
         void main() {
             var words = List<string> { "red", "green", "blue" }
             print(words.contains("green"))
             var ages = HashMap<string, int> { {"ada", 36} }
             print(ages.contains("grace"))
             print("green tea".contains("tea"))
             var n = 7
             print(n >= 1 && n <= 9)
         }

         true
         false
         true
         true

     contains asks a list, a map (by its keys) or a text. A number is held
     between two ends with >= and <=.

WHAT THE COMPILER REFUSES
   in as a test
         void main() {
             var xs = List<int> { 1, 2 }
             if 2 in xs {
                 print("yes")
             }
         }

         error: expected `{`, found `in`
           `in` is written only at the head of a `for`
           --> example.sg:3:10
          3 |     if 2 in xs {
            |          ^^
           hint: whether a collection holds a value: `xs.contains(2)`

     The test is written if xs.contains(2). print(2 in xs) is refused the same
     way.

   A for without in
         void main() {
             var xs = List<int> { 1, 2 }
             for x of xs {
                 print(x)
             }
         }

         error: expected `in`, found `of`
           --> example.sg:3:11
          3 |     for x of xs {
            |           ^^

   Two names before in
         void main() {
             var xs = List<int> { 1, 2 }
             for i, x in read xs {
                 print(x)
             }
         }

         error: a `for` has one loop variable
           --> example.sg:3:10
          3 |     for i, x in read xs {
            |          ^
           hint: with the positions: `for i in 0..xs.length()`, and the item is `xs[i]`

     A for has one name. For the positions too, go over 0..xs.length() and
     read xs[i].

   in as a name
         void main() {
             var in = 3
             print(in)
         }

         error: expected a variable name, found `in`
           `in` is a word of the language, not a name
           --> example.sg:2:9
          2 |     var in = 3
            |         ^^
