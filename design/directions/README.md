# Directions

Four larger parts of the language were set out as a whole before the first slice of each was built: what they take
from other languages, the order of their slices, and the rows decided together. Each slice then decided its own
details, which are in [the decisions by topic](../rules/README.md).

| Page | Decided | What it sets out |
|---|---|---|
| [Async, the direction](async.md) | 14 November 2026 | C#'s behaviour compiled the way Rust compiles it: `async`, `await`, `Task<R>`, cancellation |
| [Calling C, the direction](calling-c.md) | 15 November 2026 | Raw memory, `extern` blocks and their calls, then `Disposable`, opaque C types and C structs |
| [Reaching what C reaches, the direction](reaching-what-c-reaches.md) | 16 November 2026 | No preview while C can do work SG cannot: the parts that close the gap |
| [Windows, the direction](windows.md) | 17 November 2026 | How SG reaches Windows beside Linux and macOS |
