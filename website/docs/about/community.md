# Community

SG has two places to talk, and they are for the same things, so choose the one that suits you:

- **The mailing list**, [SG Language](https://groups.google.com/g/sg-lang) on Google Groups, if you would rather
  read and write by email. You need no account.
- **[Discussions](https://github.com/selcukgural/sg-lang/discussions)** on GitHub, if you already have a GitHub
  account and would rather write on the web, beside the code and the issues.

There is no chat server and no social media account. SG is made by one person, and two places read once or twice
a day are what one person can keep up with, and answer well.

## The mailing list

- **Join by email:** send an empty message to
  [sg-lang+subscribe@googlegroups.com](mailto:sg-lang+subscribe@googlegroups.com) and answer the confirmation
  that comes back.
- **Or on the web:** open [the group](https://groups.google.com/g/sg-lang) and choose *Join group*. You can choose to
  get every message, a daily digest, or nothing by email and read on the web.
- **Write** to [sg-lang@googlegroups.com](mailto:sg-lang@googlegroups.com) once you have joined, or start a
  conversation on the web. Replies by email go to the whole list.
- Your first message waits until the author lets it through, to keep spam out; the messages after it go out at
  once.

Everyone can read the archive on the web without joining. To leave, send an empty message to
[sg-lang+unsubscribe@googlegroups.com](mailto:sg-lang+unsubscribe@googlegroups.com).

## Discussions on GitHub

[Discussions](https://github.com/selcukgural/sg-lang/discussions) has four categories:

| Category | For |
|---|---|
| [Q&A](https://github.com/selcukgural/sg-lang/discussions/categories/q-a) | A question about SG; the answer that solved it can be marked |
| [Ideas](https://github.com/selcukgural/sg-lang/discussions/categories/ideas) | An idea for the language, its library or its tools |
| [Show and tell](https://github.com/selcukgural/sg-lang/discussions/categories/show-and-tell) | Something you built with SG |
| [Announcements](https://github.com/selcukgural/sg-lang/discussions/categories/announcements) | News of the project; only the author writes here |

## In both places

- Write in English or in Turkish.
- Answers can take a few days. A question with a short program that shows it, and what you expected it to do, is
  the quickest to answer.
- News of the project (a preview, a change that breaks programs) goes to both: to the list under a subject that
  starts with `[ANN]`, and to Announcements.

## Where each thing goes

| You have | Send it to |
|---|---|
| A question, an idea, something you built with SG | [The mailing list](https://groups.google.com/g/sg-lang) or [Discussions](https://github.com/selcukgural/sg-lang/discussions), whichever you like |
| A bug: a program that does the wrong thing, a message that is wrong, a crash | [An issue on GitHub](https://github.com/selcukgural/sg-lang/issues) |
| A security problem: a program the checker accepts that reads or frees memory it should not | Privately, as [the security policy](https://github.com/selcukgural/sg-lang/blob/main/SECURITY.md) says; never to the list, Discussions or an issue |
| A mistake on this site | *Edit this page* at the bottom of the page, or an issue |

Be kind to each other. Messages that attack a person, and advertisements, are removed, and whoever sends them
is taken off the list and out of Discussions.
