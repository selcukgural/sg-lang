# Community

SG has one place to talk: a mailing list, [SG Language](https://groups.google.com/g/sg-lang) on Google Groups.
There is no chat server and no social media account. SG is made by one person, and a list read once or twice a
day is what one person can keep up with, and answer well.

## Joining

- **By email:** send an empty message to
  [sg-lang+subscribe@googlegroups.com](mailto:sg-lang+subscribe@googlegroups.com) and answer the confirmation
  that comes back. You need no Google account.
- **On the web:** open [the group](https://groups.google.com/g/sg-lang) and choose *Join group*. You can choose to get
  every message, a daily digest, or nothing by email and read on the web.

Everyone can read the archive on the web without joining. To leave, send an empty message to
[sg-lang+unsubscribe@googlegroups.com](mailto:sg-lang+unsubscribe@googlegroups.com).

## Writing to the list

Once you have joined, write to [sg-lang@googlegroups.com](mailto:sg-lang@googlegroups.com), or start a
conversation on the web. Replies by email go to the whole list.

- Write in English or in Turkish.
- Your first message waits until the author lets it through, to keep spam out; the messages after it go out at
  once.
- Answers can take a few days. A question with a short program that shows it, and what you expected it to do, is
  the quickest to answer.
- News of the project (a preview, a change that breaks programs) is sent to the list too, under a subject that
  starts with `[ANN]`.

## Where each thing goes

| You have | Send it to |
|---|---|
| A question, an idea, something you built with SG | [The mailing list](https://groups.google.com/g/sg-lang) |
| A bug: a program that does the wrong thing, a message that is wrong, a crash | [An issue on GitHub](https://github.com/selcukgural/sg-lang/issues) |
| A security problem: a program the checker accepts that reads or frees memory it should not | Privately, as [the security policy](https://github.com/selcukgural/sg-lang/blob/main/SECURITY.md) says; never to the list or an issue |
| A mistake on this site | *Edit this page* at the bottom of the page, or an issue |

Be kind to each other. Messages that attack a person, and advertisements, are removed, and whoever sends them
is taken off the list.
