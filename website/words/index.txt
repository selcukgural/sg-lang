# The names of the index (reference/index.html) that have no page of their own yet: one on each line, as
# kind | name | what it is, in one line. A name with a page (a .md file in this folder) takes its line from
# that page, and its line here is left out. The types of the library come from the headings of
# docs/library/, the modules from the pages there. A line here is a draft until its page is written: each is
# checked against design/rules/ then.

keyword | alias | gives a type a second name: alias Scores = List<int>
keyword | align | align(N) keeps a type at a multiple of N bytes
keyword | checked | shared checked T: borrows of it are checked while the program runs
keyword | embed | embed("logo.gif"): the bytes of a file, put into the program
keyword | export | makes a function that C calls
keyword | extern | declares the functions of a C library
keyword | interface | what a type can do: Clonable, Formattable, Equatable, Comparable
keyword | not | is not: the test of is, the other way round
keyword | packed | a struct with no padding between its fields
keyword | readonly | a field given when the value is built and never changed
keyword | union | holds one of its fields at a time in the same bytes
keyword | weak | a link that does not keep its value alive

type | float | a fraction of 32 bits
type | nint | an integer as wide as an address: what length() gives
type | nuint | nint without a sign
type | sbyte | an integer of 8 bits, -128 to 127
type | short | an integer of 16 bits
type | uint | an integer of 32 bits without a sign
type | ulong | an integer of 64 bits without a sign
type | ushort | an integer of 16 bits without a sign
type | void | the type of a function that gives nothing back

value | false | the bool that is not true
value | true | the bool that is not false

sign | a..b | a range: from a up to, not with, b
sign | xs[^1] | an index counted from the end
sign | c ? a : b | a when c is true, b when it is false
sign | $"{x}" | text with values written into it

command | sg | runs a program: sg hello.sg, or a folder
command | sg test | runs the tests of a file or of every module in a folder
command | sg build | compiles through C: a program, a library, or an object without an operating system
command | sg emit-c | prints the C
command | sg lsp | the language server an editor starts
command | sg help | the page of a word of SG in the terminal, with no network: sg help read
command | sg add | adds a package to sg.project; with update, remove and lock
