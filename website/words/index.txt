# The names of the index (reference/index.html) that have no page of their own yet: one on each line, as
# kind | name | what it is, in one line. A name with a page (a .md file in this folder) takes its line from
# that page, and its line here is left out. The types of the library come from the headings of
# docs/library/, the modules from the pages there. A line here is a draft until its page is written: each is
# checked against design/rules/ then.




sign | c ? a : b | a when c is true, b when it is false

command | sg | runs a program: sg hello.sg, or a folder
command | sg test | runs the tests of a file or of every module in a folder
command | sg build | compiles through C: a program, a library, or an object without an operating system
command | sg emit-c | prints the C
command | sg lsp | the language server an editor starts
command | sg help | the page of a word of SG in the terminal, with no network: sg help read
command | sg add | adds a package to sg.project; with update, remove and lock
